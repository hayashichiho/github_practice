# Quest 8: タスク名を編集する

## やること

タスク名を編集できるようにしてください。編集開始、保存、キャンセルを行える小さな操作を追加します。

## 完了条件

- 編集操作で現在のタスク名を入力欄に表示する
- 保存で対象タスクの名前だけを更新する
- 空欄では保存できない
- キャンセルすると変更前の名前に戻る
- 編集・保存・キャンセルの重要な動作をテストする
- `npm test` と `npm run build` が通る

## ハッカソンで役立つ知識: 分担と変更範囲

同じファイルを同時に変更すると競合しやすくなります。チームでは、担当する機能と変更予定のファイルをIssueで共有し、着手前に重なりを確認します。今回はPR本文に、変更したファイルとその理由を簡潔に書いてみてください。

## Git Quest

branch名の数字と `Closes` の番号は例です。Quest番号ではなく、GitHubで作成されたこのIssueの実際の番号に置き換えてください。最新mainからbranchを作ります。

`feature/8-edit-task` branchを作り、PR本文に `Closes #8` を入れます。操作ボタンのaccessible nameも確認しましょう。
