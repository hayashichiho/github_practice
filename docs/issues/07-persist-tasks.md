# Quest 7: タスクをブラウザーに保存する

## やること

追加・完了切り替え・削除を行っても、ページを再読み込みした後に状態が残るようlocalStorageへ保存してください。

## 完了条件

- タスク一覧をlocalStorageへ保存する
- 初回起動時に保存データがなければ初期タスクを表示する
- 保存データが不正な場合もアプリがクラッシュしない
- 保存と読み込みのテストを追加する（必要ならlocalStorageをテストで初期化する）
- テストとbuildが通る

## ハッカソンで役立つ知識: 再現手順を共有する

エラーが出たら「実行したコマンド・期待した結果・実際の結果・試したこと」をIssueに記録します。「動かない」だけでなく、再現できる情報があるとチームで原因を調べやすくなります。ログにトークンやパスワードを貼らないようにしてください。

## Git Quest

branch名の数字と `Closes` の番号は例です。Quest番号ではなく、GitHubで作成されたこのIssueの実際の番号に置き換えてください。最新mainからbranchを作ります。

`feature/7-persist-tasks` branchを作成し、PR本文に `Closes #7` を入れます。ブラウザー内の保存情報は機密情報向けではありません。
