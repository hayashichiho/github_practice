# Quest 4: タスクを完了・未完了に切り替える

## やること

各タスクの丸いボタンを押すと、完了と未完了が切り替わるようにしてください。完了時は現在の取り消し線と「完了」表示を使います。

## 完了条件

- 未完了タスクを押すと完了状態になる
- もう一度押すと未完了に戻る
- 他のタスクの状態は変わらない
- ボタンのaccessible nameが現在の操作を説明している
- 状態変更のテストを追加し、テストとbuildが通る

## ハッカソンで役立つ知識: PRを小さくする

PRは1つの目的に絞るとレビューしやすくなります。今回は完了切り替えだけを変更し、別の機能や無関係な整形を混ぜないようにしてください。PR本文には「何を変えたか・どう確認したか」を書きます。

## Git Quest

branch名の数字と `Closes` の番号は例です。Quest番号ではなく、GitHubで作成されたこのIssueの実際の番号に置き換えてください。最新mainからbranchを作ります。

`feature/4-toggle-task` branchを作成します。PR本文には `Closes #4` を入れます。
